# Laboratorio

Repositorio personal de pruebas, ideas y experimentos. Espacio abierto, sin
relación con ningún otro proyecto: sirve para investigar cosas, probar
tecnologías y decidir después si algo merece repositorio propio.

## Estructura

```
ideas/         ideas sin desarrollar, una por archivo
experimentos/  pruebas con código, una carpeta por experimento
notas/         apuntes, referencias y lecturas
```

## Cómo se usa

- Cada idea nueva → un archivo en `ideas/` con el formato `AAAA-MM-DD_slug.md`.
- Cada experimento → una carpeta en `experimentos/` con su propio `README.md`
  que explique qué se prueba, cómo ejecutarlo y qué se ha aprendido.
- Nada aquí es definitivo. Lo que crezca y se consolide se saca a su propio
  repositorio; lo que no funcione se archiva o se borra sin ceremonia.
