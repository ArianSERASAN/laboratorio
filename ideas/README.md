# Ideas

Ideas sin desarrollar. Un archivo por idea, nombrado `AAAA-MM-DD_slug.md`.

Plantilla sugerida:

```markdown
# Título de la idea

**Qué es:** una o dos frases.

**Por qué:** qué problema resuelve o qué curiosidad responde.

**Cómo empezaría:** el primer paso concreto, no el plan completo.

**Estado:** idea | en experimento | descartada | repositorio propio
```
